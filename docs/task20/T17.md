# T17 — storage bridge contracts

Baseline `e6578d18eeab6e8030727025f5cd57e974afa619` (signed accepted T16). Contract recorded before implementation; all five criteria and 21 assigned source decisions require two independent acceptors before commit.

Storage metadata codecs receive schema-canonical present scalars (string, bool,
int64, finite float64). An absent whole attribute set normalizes to nil; custom
codecs must accept nil/empty equivalently. This preserves the existing schema
normalizer and ES/Qdrant boundary without adding allocations. PG must
normalize decoded UseNumber attributes before custom Decode and invoke Decode on
empty wire. ES preserves the nil-empty contract after field projection;
Qdrant normalization already supplies it. JSONCodec still accepts raw transport
attributes and normalizes defensively. Null/wrong-kind/nonfinite present values
remain invalid at admission, omission retains the portable two-valued truth table.
MatchIR requires admitted schema-normalized lookup values. Keep public field
constructors on built-in scalar types; no speculative alias expansion. Nil builder
and unfinalized construction return ErrInvalidArgument.

ES owns a deep copy of SynonymMap and SearchFields. Tokenizer/codec/client remain
host callbacks, stable and concurrent-safe. For each successful query, tokenize
once, expand those tokens once, use that exact expansion for empty admission and
wire dispatch. No new tokenizer framework or hidden rerun.

PG accepts the existing single ASCII identifier grammar, then double-quotes the
validated table name, preserving uppercase/keywords. No schema-qualified names or
new identifier grammar. Values remain bound parameters. Hosts bound Upsert batches
and statement/driver capacity; keep one atomic SQL statement, no implicit chunked
partial commits. Equal-distance order is unspecified (rank records the actual
backend order), retaining the distance-only query and ANN planner compatibility;
no deterministic tie or ANN recall promise. Rows.Close is cleanup-only in this host
bridge profile; query outcome errors belong in Rows.Err and are checked explicitly.
Close cleanup diagnostics are host-observed, not converted into speculative late
query outcomes. Retain visible defer Close without a generic error framework.

Neo4j remains a Runner bridge, unrestricted current-only. Reject nonempty generic
Filters before Runner traversal; only Graph.NodeFilter/EdgeFilter have graph domain
semantics. Retrieve validates document projection (ID/content), preserving ordinary
valid-prefix projection errors; labels/edges/schema metadata are outside that
projection. Traverse/Upsert still normalize full graph snapshots. Preserve T10
final delivery/cancellation privacy gates and single callback invocation.

Deletion bridges require exact nonnegative affected counts, including zero.
Unknown/asynchronous outcomes must be resolved by the host or rejected explicitly
(ErrUnsupported when an exact-count profile cannot be supplied), never replaced
by request length or guessed zero. Retain the exact-only DeleteResult contract;
reject negative/unrepresentable reported counts as protocol. Raw FindByIDs/Delete
remain explicit administration, separate from bound retrieval. No transport,
retry, migration, DDL or remote profile inspection is added by constructors.
