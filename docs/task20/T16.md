Baseline `5775f4ee0b1aeb11feb634cbb480a670ace0c7ce` (accepted T15 signed commit). Contract recorded before implementation; acceptance pending.

Tensor supports Dot and NormalizedDot. Only NormalizedDot requires unit rows; native MaxSim sums can be negative or exceed one. CandidateBudget bounds supplied candidate count, not tokens, dimensions, bytes or arithmetic. Hosts bound input matrices. Context checks occur during row validation, between candidates and token pairs, and around ranking; a component row and standard-library sort remain indivisible cooperative work. Cancellation discards scores/ranking.

BM25 configuration changes to an optional aggregate `Parameters *BM25Parameters`. Nil selects K1=1.2/B=0.75; an explicit aggregate permits K1=0 and B=0. Constructor copies the aggregate, accepts finite K1>=0 and B in [0,1], and retains nonfinite computed-score rejection. Remove ambiguous scalar Config.K1/B; migrate compiled conformance consumers. Historical ignored reproduction artifacts remain unchanged. Score accumulation and result construction gain context checkpoints; sorting remains cooperative at entry/exit. TopK bounds delivery only; Threshold belongs to terminal composition. No CPU/cache/clone optimization is planned.

Candidate-provider budget counts backend documents before reference deduplication. Unique references retain first occurrence; exact reranking never implies whole-index recall or ANN. Persistent pinned catalogs can scan more than TopK. MaxRecords keeps its existing separate uses: per-stage records, per-catalog records, candidate limit, inventory key count and aggregate observed inventory records; document each unit without conflating memory/CPU bounds.

Retain repeated admission, freshness and owned-clone boundaries: each fences a different ownership or publication transition. Retain safe generation-wide invalidation and inventory checks on cache hits. MaxCachedSnapshots counts resident snapshots, not bytes or concurrent transient builds. Raw metadata is borrowed immutable; tokenizer and codec are host-owned stable concurrent callbacks.

Dense and tensor manifest selectors explicitly exclude Retired as well as tombstoned/unpublished entries. Keep their type-specific storage mechanics and visible gates; a generic storage engine or helper hiding publication gates would enlarge this task without removing a demonstrated defect. Existing redacted query errors preserve protocol/cancellation semantics. Root is trusted host provisioning, not a hostile-filesystem sandbox. Preprovision durable ancestors; file/root fsync does not prove ancestor creation or hardware power-loss durability. Local Darwin/Linux nonblocking flock conflicts immediately; lock lifetime belongs to the returned unduplicated handle, not an abstract process. Validate process restart/crash profiles without claiming power-loss tests.
