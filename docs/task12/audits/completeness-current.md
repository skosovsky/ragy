## Метод и denominator

Прочитан полный `.cursor/docs/task12.md` (577 строк), §§1–10, а не только существующая матрица. Обязательные normative clauses разбиты независимо на атомы ниже. Повторение одного условия в §§4/5/6/7/10 не добавлялось как второй функциональный requirement; отдельно считаются конечные deliverables, реальные эксперименты и final-audit gates. Optional означает opt-in runtime, а не возможность не поставлять capability. Каждый атом имеет одинаковый вес. Partial, неподтверждённое, blocked и отсутствующий experiment дают 0; verified даёт 1. Source support authenticity, hardware powerloss, arbitrary driver/service semantics, OCR quality и production quality не расширялись за явно ограниченный scope ТЗ.

`docs/task12/requirements.md` использовалась только для поиска реализации: её существующие pending/partial статусы не были приняты как verdict. Например actual durable lifecycle, graph stages и PDF parser tests уже подтверждают многие старые partial строки. Conversely green make не подтверждает live experiments.

Проверены Go contracts и implementation boundaries (`access`, `retrieval`, lifecycle targets, tensor query, recipes, graph resolution/history, evidence, source/layout), regression/integration/external tests, saved actual artifacts и весь актуальный all-module lint/test checkpoint. Повторно исполнены четыре независимых schema validators: coverage7+/12−, lifecycle4+/13−, evidence16+/32−, locator6+/22−; все exit0. Broad make не повторялся этим аудитором. Во время аудита root сообщил о parallel correctness fixes после locator-envelope checkpoint: per-query ownership, finite BM25 parameters/scores, exact dense/tensor cleanup supports. Старые full logs подтверждают только прежний checkpoint; D-04/D-05 теперь U до current broad checks. Сам аудитор implementation не менял. Проверяемые классы full-log: 13/13 имеют PASS; отсутствующие: нет.

Существующие full logs не содержат криптографическую source fingerprint. Следовательно verdict относится к инспектированному текущему checkpoint; последующие semantic изменения требуют затронутых проверок, а final gate — повторной сверки. Не заявляю поддержку любой внешней infrastructure.

## Ограничения независимого аудита

Это аудит полноты. Он не заменяет второго correctness auditor и не утверждает, что подтверждённых или скрытых defects нет. Tests прочитаны выборочно по профильным assertions и сверены с full race log; исчерпывающего формального доказательства callbacks/host implementations нет. Не исполнялись внешние платные model calls, live databases, production corpus или аппаратное powerloss. Ни release, ни публикация, ни закрытие issue не выполнялись. Репозиторий не изменён, кроме этого отчёта.

Для окончательного100% требуется повторить count по тому же списку после закрытия U, проверить существенные изменения после checkpoint и получить final-state outcome второго независимого auditor. Удаление U из denominator, переименование unperformed в negative или заполняющий placeholders artifact не разрешают приёмку.
