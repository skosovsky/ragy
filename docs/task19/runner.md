# TASK19 verification runner

The single correctness gate (run from repository root) is:

```sh
python3 scripts/task19_verify.py \
  --actual-pdf /Users/skosovsky/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 \
  --lint /opt/homebrew/bin/golangci-lint \
  --output docs/task19/results/final
```

Use a Python interpreter with `pdfplumber` and `pypdf` for `--actual-pdf`. Omit that flag to run the portable local profile; actual-parser tests then appear as **skipped**, never passed. When `--actual-pdf` is explicitly selected, readiness alone is insufficient: all eight pinned actual test parents and their emitted subtests must execute and pass. Missing/skipped actual tests retain their skipped profile status but produce a failed `required-profile:actual-pdf` gate. The Homebrew linter is optional and must support the repository Go version; its version is captured. The runner does not install interpreters, packages or tools. All commands run with `GOWORK=off`; every one of the 14 root/nested modules runs `go test -json -race -count=1 -timeout=590s ./...` independently. A failing module does not stop later modules or lint checks. Default 600-second subprocess limits kill the isolated process group on timeout. `--timeout` configures the finite bound. `--go` selects a Go executable.

The default `uncached-tests` mode disables Go test-result reuse with `-count=1`, while retaining the explicitly recorded compiler/module caches. `--cache-mode reuse-tests` permits Go result reuse and records cached package output separately. `GOCACHE`, `GOPATH`, `GOMODCACHE`, `GOLANGCI_LINT_CACHE` and `TMPDIR` preserve host configuration or use documented `/tmp/ragy-*` defaults. Compiler/module-cache warmth is not inferred from a passing test. Logs and the JSON matrix record commands, exit codes, timeouts, elapsed observations, Go/tool versions, revision, working-tree status and individual test/package pass/fail/skip events. No credentials or full environment are dumped. Raw subprocess logs remain alongside `matrix.json`; partial progress is written after every module.

Provider smoke tests remain explicit opt-ins: `--live` only allows the existing `RAGY_LIVE_GEMINI=1` / `RAGY_LIVE_PROVIDERS=1` / `RAGY_PROVIDER_SMOKE=1` switches to reach tests; it never supplies credentials or enables them itself. Gemini multimodal additionally needs its configured PNG. Without `--live`, those switches are removed from subprocess environments, even if set by the caller. The matrix derives each live-provider profile from actual `TestLive*` / `TestProviderSmoke` outcomes. Missing keys or disabled switches therefore stay skipped. These checks can incur provider charges only after the caller explicitly selects live execution. External PostgreSQL/Qdrant/Elasticsearch/Neo4j services are **skipped / unverified**: this runner has no provisioned host service bridge. Adapter transport fixtures are local contract evidence.

Correctness checks, provider fixtures, actual PDF and live profiles are separate matrix entries. By default retrieval quality is explicitly skipped. Add `--evaluation development` to run the fixed local text, graph and tensor consumer commands against development data, or `--evaluation holdout` only after the documented strategy freeze and holdout publication. Evaluation output and process status are stored separately; execution success does not imply a quality gain. Explicit evaluation selection requires newly produced valid output with matching dataset/split/digests, all strategy × query × three-repeat rows exactly once, complete metric coverage and denominators, and no execution-failed rows. The required mechanical gate rejects per-row or aggregate source/scope/stale/citation violations, unknown local compliance, invalid original citation identities/coverage, and breaches of the frozen local policy: at most 12 originals per retrieval dispatch, 36 unique candidates per attempt, six retrieval slots, three combined model/encoder/reranker slots, 1800 context bytes, five seconds, 262144 serialized input bytes and 65536 serialized output bytes. These local byte units include vector/tensor payloads and are not provider tokens; provider billing remains unavailable. Declared limits cannot be raised inside a report. Recall/MRR/nDCG losses or no quality gain remain valid study outcomes and do not fail the mechanical gate. Stale artifacts are removed from the selected output destination before execution; zero exit with missing/incomplete JSON produces a failed required-profile check. Use a new `--output` directory to retain historical runs. These deterministic commands do not call paid providers. No arbitrary shell command is accepted. This runner does not measure provider effectiveness, latency percentiles or production readiness. Local all-module success may coexist with explicitly skipped real services.

## Independent provider-fixture audit

`scripts/task19_wire.py` runs as part of the command above. Its separately declared [pinned contracts](provider-wire-contracts.json) were reviewed against official sources on 2026-10-06:

- [Gemini embedding REST contract](https://ai.google.dev/api/embeddings) and [multimodal/purpose guidance](https://ai.google.dev/gemini-api/docs/embeddings).
- [OpenAI embedding REST contract](https://developers.openai.com/api/reference/resources/embeddings/methods/create).
- [Cohere v2 rerank REST contract](https://docs.cohere.com/v2/reference/rerank).
- [Jina dense purpose contract](https://jina.ai/news/jina-embeddings-v3-a-frontier-multilingual-embedding-model/) and [ColBERT multi-vector contract](https://jina.ai/news/jina-colbert-v2-multilingual-late-interaction-retriever-for-embedding-and-reranking/).

The audit imports no adapter implementation or Go wire structs. It parses existing TASK15 raw response literals against independent expectations for model, cardinality, indices, vector dimensions, finite float32 values and nonnegative usage; Cohere rerank checks finite relevance scores and billed search units. It requires the documented request endpoint/model/input/purpose assertions to remain present, and validates the existing adversarial raw JSON table separately. Gemini dense/multimodal share the wire decoder, so their malformed-response table is shared explicitly. Request assertions are a source audit, not an independent execution of the HTTP client; the separate Go tests exercise the real client. This limitation is intentional and visible. Both evidence classes remain local fixtures, not live provider verification. Source and contract SHA-256 digests identify exactly what was audited. A provider document changing later requires a new reviewed contract revision, not silent adaptation from current client structs.
